# lmaws ↔ lmcloud comparisons

Native writes run once with profile `lmaws`; native evidence can be reused. Read-only runs use `default`. IAM is deliberately skipped. Resource names are compared after replacing each unique run ID; payload objects/items are separately noted because the SDK ledger tracks their owning parent. Provider cost is a conservative upper bound reserved before plan, not measured API request accounting; native costs use observed SDK attempts and lifetimes. Timings are end-to-end (native rendering versus multiple provider phases), with a shared warm provider cache. Raw state and logs stay under ignored `compare/runs/`.
